# Experiments

Reserved for **Stage 2** independent computational reproduction and later regression checks.

No experiment is part of the proof trust boundary.

Every experiment added here should record:

- mathematical quantity computed;
- implementation method;
- exact parameter ranges;
- exclusions / endpoint conventions;
- independent reference method where feasible;
- raw or reproducible output;
- commit/runtime provenance.

Do not place unlabelled exploratory output in the repository.
